# Paint Panic!
## Concepto
**Paint Panic!** es una experiencia interactiva inspirada en la idea de un Mario Paint llevado a un formato de instalación.

El usuario se encuentra frente a un lienzo gigante y puede crear utilizando diferentes herramientas: brochas, colores, formas y efectos. El lienzo puede comenzar como un espacio completamente blanco o como una imagen/escena sobre la cual pintar.

Pero existe un problema: un personaje está constantemente interfiriendo con la creación.

Mientras el usuario pinta, el personaje puede borrar partes del dibujo, cambiar colores, pintar encima, mover elementos o realizar otras acciones inesperadas. De esta manera, el objetivo no es solamente crear una composición, sino intentar mantener el control del lienzo mientras este se encuentra constantemente en conflicto con el usuario.

La detección de movimiento corporal será el mecanismo principal de interacción. Los movimientos del usuario determinarán diferentes acciones tanto sobre el lienzo como sobre el comportamiento del personaje.
